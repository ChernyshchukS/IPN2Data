# IPN2Data

Извлечение данных из индивидуального налогового номера (ИПН)

## Описание

Приложение IPN2Data создано для работы
с [регистрационными номерами учетных карточек налогоплательщиков (РНОКПП)](https://uk.wikipedia.org/wiki/Реєстраційний_номер_облікової_картки_платника_податків)
они же индивидуальные налоговые номера (ИПН). Извлекайте информацию, которая содержится в этих
номерах, проверяйте корректность предоставленных данных. Для работы программы не нужны сторонние
базы - [вся информация уже содержится в номере](./assets/IPN_structure.md).

## Основные возможности

- Вводите известные Вам ИПН и получайте данные, которые они содержат.
- Проверяйте корректность полученных ИПН
- Создавайте ИПН по заданным условиям
