## Запуск тестов

### Выполнить в терминале Android Studio:

```
./gradlew :rnokpp:test
```

Если тесты проходят: `BUILD SUCCESSFUL`

## Сборка библиотеки отдельно от приложения

Одно из преимуществ Kotlin/JVM-модуля — его можно собирать независимо.

### Выполнить:

```
./gradlew :rnokpp:build
```

Gradle выполнит компиляцию, тестирование и сборку библиотеки.

Результат появится в: rnokpp/build/libs/

Этот JAR можно использовать в других JVM-проектах при условии совместимости версий Java и Kotlin.

Для текущего Android-приложения нужно использовать

```
implementation(project(":rnokpp"))
```
